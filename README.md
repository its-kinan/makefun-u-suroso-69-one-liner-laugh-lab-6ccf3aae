One original one-line laugh: the excuse a robot vacuum gives after eating a sock — the sock signed an NDA on the way down, so the vacuum can neither confirm nor deny lunch. A deterministic program writes the line to `/output/entry.txt` — no network, no randomness, no timestamps.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
